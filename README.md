# Morning Motivation – Automated Email Sender

A simple Python project that sends a motivational quote to your email every morning automatically.
This project was built to practice Python automation, file handling, SMTP email sending, and scheduling tasks.

# What This Project Does

Picks a random motivational quote from a text file

Sends it to your email inbox using Python

Can be scheduled to run every morning using:

Windows Task Scheduler

Linux cron jobs

Helps me learn automation and understand how email protocols work

# What I Learned

How to read files in Python

How to send emails using smtplib

How to automate repetitive tasks

How to schedule Python scripts

Basics of environment variables (for hiding passwords)

# How It Works

The program opens quotes.txt

Chooses a random quote

Connects to an email server

Sends the quote to your email

Python
